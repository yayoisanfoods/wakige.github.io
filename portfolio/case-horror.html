01 / INTERACTIVE WEBSITE

3つの扉。
その先は、運まかせ。

心霊サイト — ランダムな驚きをつくる

種別
既存の自主制作サイトを再構成
制作内容
3つの扉・確率分岐・画像と音声の演出
使用技術
HTML / CSS / JavaScript / 生成AI / 合成音声
素材
新規生成画像・新規の合成音声

1/3のホラー。
2/3の、まさか。

既存サイトのランダムな驚きという発想をもとに、青空の下に装置の扉を3つ配置。いずれかをクリックすると、その都度1/3の確率でホラー画像、2/3の確率で仲睦まじい成人カップルの画像を表示します。

01 / SELECT

等間隔に並ぶ3つの扉

実写風の画像に、位置を合わせた操作領域を配置。スマートフォンでも扉の横並びを維持します。

02 / REVEAL

画面いっぱいの、1秒間

どちらの分岐も画像を全画面に拡大して横揺れさせ、「キャー」の合成音声を再生。約1秒で扉選択のトップ画面に戻ります。

短い演出を、確実に終える。

画像を事前に読み込み、演出中の連打を防止。終了時は画像・音声・スクロール固定を解除します。音声の切り替えとEscキーでの終了に対応し、端末で動きを減らす設定が有効な場合は横揺れを抑えます。

各クリックの独立した抽選です。3回押したら必ず1回ホラーになる仕組みではありません。画像内の人物・造形は架空です。ブラウザーの制限や読み込み状態により音が再生されない場合があります。
